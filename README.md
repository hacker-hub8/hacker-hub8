## 🔐 About HackerHub8

**HackerHub8** is a non-profit cybersecurity community that aims to:
- Educate students and beginners in cybersecurity
- Share tools, scripts, and educational resources
- Promote ethical hacking and responsible disclosure
- Conduct workshops, awareness campaigns, and hands-on sessions
